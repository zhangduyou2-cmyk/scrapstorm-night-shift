SCRAPSTORM: NIGHT SHIFT — v0.5.1
Creator: zhangduyou2-cmyk / AI-assisted development: OpenAI Codex

WINDOWS: PLAY WITHOUT INSTALLING
1. Extract the complete ZIP into a normal folder. Do not run inside the ZIP viewer.
2. Double-click Play.cmd. You can also open Scrapstorm.exe directly.
3. Keep Scrapstorm.exe, Scrapstorm.pck and all included notices together.
No Godot editor, Python, Node, administrator account or installation is required.
The build is unsigned; Windows may show an unknown-publisher notice.

Play.cmd restores an existing window from THIS executable path, including hidden,
minimized or off-screen windows. It does not close or reuse a recording build.
If launch fails, the command window stays open and reports the problem.
Launcher diagnostics: %LOCALAPPDATA%/Scrapstorm-Launcher/launcher.log

First launch is English. Open SETTINGS and choose 简体中文 if preferred.
WASD: move. Mouse: aim. Hold right button: reclaim; release: discharge.
Space: dash. E: active skill. Esc: pause/back. Tools attack automatically.
OVERTIME: endless rooms. NIGHT SHIFT: three sectors. QUICK SWEEP: three minutes.
Shop thinking time is unlimited and never recorded.

SAVES
This package contains NO player profile, settings, unlocked rewards or recording mode.
On a computer/account that has not played before, progress starts fresh.
On the same Windows account, later launches keep that player's existing progress.
Re-extracting the ZIP does not reset saves. Deleting the game folder does not erase them.
Location: %APPDATA%/Godot/app_userdata/SCRAPSTORM- NIGHT SHIFT/
Standard/endless runs resume from the latest shop checkpoint, not any combat frame.
The creator's separate recording edition uses its own directory and is not included.
