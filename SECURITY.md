# Security / 安全反馈

This is a small portfolio project, without a staffed security response service or a response-time guarantee. Fixes target the current source version; older prototype builds are retained as development history, not maintained release branches.

For crashes, balance, UI problems, and corrupted saves, use a normal bug report after removing private file paths and personal data. Do not attach passwords, tokens, or an entire user-data directory.

For a suspected security issue, use the repository's **Security → Report a vulnerability** option if the owner has enabled private vulnerability reporting. If that option is absent, open a minimal issue requesting a private reporting channel without publishing exploit details or personal information. Private reporting is a repository setting and has not been assumed enabled by these source files.

Checksums beside local packages detect an accidental mismatch; they are not a digital signature. Windows builds are currently unsigned. Build from reviewed source or use artifacts published by the project owner. There is no auto-updater.

安全问题优先使用 GitHub 仓库已启用的私密报告入口；入口不存在时，只提出私密联系请求，不在公开 issue 中贴令牌、个人路径或攻击细节。当前维护对象为最新源码，不承诺旧原型的长期维护。
