## 下一步顺序

1. **完成首次公开准备。** 保留真实贡献说明和素材来源，确认许可，检查干净源代码副本可构建、公开内容没有个人路径或凭据。只有获得发布授权后创建/推送仓库和 Release；正式下载和试玩链接存在后再接入 README。
2. **补齐最终 Web 流程。** v0.5.1 两次普通输入都在首店前自然死亡，不能沿用 v0.5.0 的完整 Web 通过结果。后续需覆盖商店购买、路线、刷新续玩、下一房和首领，并继续保留真实失败样本。
3. **真人打磨主打无尽。** 观察新玩家如何理解回收喷射、路线风险、目标与首领反制；评估 6/12/24 房追求、修理和撤离取舍、八工具获取与四槽搭配。自动首领夹具的十二场获胜不能代替玩家难度反馈。
4. **长局和表现稳定性。** 在较低配置、不同浏览器和窗口尺寸完成较长无尽局，记录帧时间尖峰和对象上限；听测三首 BGM 的循环疲劳、技能声与危险提示；检查历史/成就节奏及奖励外观吸引力。
5. **再决定扩展。** CONTRACTS 可以采用固定装配、回收目标或首领规则挑战，先做可玩切片再开放入口。更多地图、成就、历史导出和世界模块重构按实际反馈排序，当前没有承诺的发布日期。

商店允许自由思考，始终不记录停留时长。现有地区可服务不同模式；当前不做联机、移动端、云账号、付费系统、大型剧情或永久无限战斗数值。没有用户给出的硬截止日期，不虚构排期。
