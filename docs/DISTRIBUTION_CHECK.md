# v0.5.1 · 精简分发检查

更新：2026-09-08。此源码目录是独立的公开文件副本，不带开发仓库历史、引擎、缓存、构建工具下载或录制工作台。游戏玩法版本保持 v0.5.1；Windows 启动器与分发流程更新。

## 交付方式

- 朋友试玩：发送 Windows ZIP，完整解压后打开 `Play.cmd`，也可直接运行 `Scrapstorm.exe`。无需安装编辑器、Python 或 Node。
- GitHub 仓库：上传本源码目录的内容；可执行程序 ZIP 作为 Release 附件，不放进 Git 源码历史。发布由创作者另行授权；远程状态以仓库、Release 和 Actions 实际结果为准。
- 源码包保留源素材、构建脚本、测试、双语说明、来源记录与第三方许可；不牺牲音乐、中文字体、地图或玩法来缩小下载。

## 启动和存档

启动器按可执行文件完整路径定位已运行的正式版，恢复隐藏、最小化或离开显示器范围的窗口。它只选择 Godot 的游戏窗口，不把显卡驱动创建的不可见辅助窗口当作主界面。启动互斥锁按程序路径区分；单独录制程序不会被复用或关闭。失败时保留提示并写本机启动日志。

试玩包不含 `profile.json`、`settings.cfg` 或其备份。朋友首次在自己的 Windows 账户打开游戏，为 0 金币、默认四个基础解锁、0 成就、空历史、无续关检查点、英文界面和未完成的新手引导。第二次打开保留该账户自己的进度。在作者原来的电脑账户打开正式版，仍会读取作者自己的正式存档；这不代表存档被装进压缩包。
