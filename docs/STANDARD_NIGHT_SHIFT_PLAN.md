# 标准夜班扩展与已确认设计

> v0.3 范围档案。当前 v0.5 规则与状态见 [V05_OVERTIME_PLAN](V05_OVERTIME_PLAN.md) 和 [GAME_BRIEF](GAME_BRIEF.md)。以下保留当时的决策、实施和验收，历史构建证据见 [v0.3 报告](BUILD_REPORT_v0.3.0.md)。

更新：2026-09-07。本文件记录v0.3阶段创作者授权，优先级高于旧版 Demo 路线中的待定项。当前v0.3已实现下述标准模式功能，自动/平台验收与真人难度/听感分别记录；具体数据见[v0.3构建报告](BUILD_REPORT_v0.3.0.md)。

## 创作者反馈与当前范围

- 现有玩法好玩，但首领过于简单，创作者反馈没有一次失误；应增加应对变化和场地压力。
- 采纳商店数值前后对照、独立改装图标、每店一次付费刷新、五个普通阶段差异、战斗节奏和反馈、轻量首局引导。
- 商店自由停留，不记录商店耗时，不将其纳入成绩、奖励或平衡统计。
- 本轮首先做好标准夜班，至少三张可选地图；每张都要有自己的普通敌人表现/行为、场地机制、首领和背景音乐。
- 采纳局外金币、皮肤、技能蓝图与配色、结算反馈、本地保存、操作适配以及已发现的玩法问题修正。
- 免费作品集、英语默认且支持简体中文、Windows 与桌面 Web、免费及原创资源优先，保持不变。

## 模式路线

| 模式 | 目标 | 本轮安排 |
| --- | --- | --- |
| NIGHT SHIFT 标准夜班 | 一张地图内完成分阶段清扫、购买、首领与结算；完整版战斗时长目标约 15—20 分钟，须用真实输入验证 | 主交付，三张地图开放选择 |
| QUICK SWEEP 快速清扫 | 三到五分钟体验回收与喷射，适合短局与作品集初次试玩 | 保留已有三分钟入口，随基础修正回归 |
| OVERTIME 无尽加班 | 按阶段推进事件、精英与首领变体，可撤离、波间保存；后期成长不能用尽 | 确认方向，标准模式成熟后实施；本轮不显示不可玩的入口 |
| CONTRACTS 挑战合同 | 固定特殊规则、限定构筑、回收目标与首领挑战，随时可玩 | 确认方向，标准与无尽之后扩展 |

地图与模式分开。标准模式每局选择一个区域，不要求一次连打三张。地图全部可选，避免本轮测试被重复解锁阻挡；后续内容解锁不得破坏基础玩法可达性。

## 战斗与经济修正

1. 五个普通阶段分别强调聚怪回收、突进夹击、远程突破、场地回收事件、混合围攻；阶段内包含增援与喘息，标准时长由内容支持。旧 Demo 的 55 秒阶段可继续用于兼容测试，不代表标准局长度。
2. 首领按距离和状态选择招式，预警期间允许玩家看清，锁定后不无预警追踪。二阶段组合已学会的应对，仍保证逃生间隙。
3. 预警使用实际攻击距离/宽度；处理掩体不对称安全输出；首领冲撞对减速单独处理。
4. 喷射去除少量能量重复领取固定基础伤害的优势；短喷解围，高储能有明显范围、伤害或破甲收益，容量升级在同能量下不得减伤。
5. 改善主动连续回收收益，保留波末回收兜底；伤害、维修、无敌时间分项校准，避免同时削弱所有容错。
6. 增加有取舍的装备选择，展示实际数值和当前装备详情。刷新需有明确价格、只能一次、扣款和候选更新原子化，暂停/存档后不重置机会。
7. 加入受击方向、技能命中/连锁、蓄能与爆发层次、机械碎裂和短时回收奖励提示；保留减弱特效。

## 局外成长、反馈与存档

- 能量用于当场喷射，零件用于当局商店，金币用于局外皮肤、配色和技能蓝图。
- 金币按实际完成阶段和首领结算，失败保留已完成收益；不按挂机分钟或商店剩余零件兑换。
- 蓝图解锁新技能选择，以能量/冷却/装备取舍约束，避免无限永久攻击/生命叠加。皮肤不改变碰撞和基础强度。
- 玩家技能可换色；敌方危险预警保持固定语义，同时用形状辅助辨识。
- 结算展示战斗时间、阶段、金币、构筑贡献、失败原因、个人纪录和下一个解锁目标。
- 本地进度包含版本、校验/备用恢复、一次性结算；检查点保存当前 RNG、商店候选及已售/已刷新状态。主动退出明确提示，波间支持继续。
- 首局行动引导可跳过/重看，提供吸附按住/切换选项和按键重绑；检查中英文与小窗口文字。

## 已落地的v0.3参数与边界

- 标准五阶段120/165/180/195/210战斗秒，共870秒，再实杀各图首领；现有三分钟快速清扫保留。
- 四工具三槽，新增可穿透废钢锯；六种三级改装。标准商店价格在等级基础价＋逐店附加后乘2.8并向上取整；每店一次刷新，标准价格34/51/68/84/101。当前未加入出售/锁定。
- 喷射采用按储能增长的效率曲线，移除小喷重复领取固定伤害的收益；遮挡、首领冲撞路径与环弹缺口预警有回归。首领区分冲撞/转向扫射/热区/带缺口环弹，二阶段增加组合。
- 默认电磁排斥（30能量/8秒）；黑洞压缩器（60/15，聚拢1.5秒爆炸）与电弧过载（45/12，恢复冲刺并4秒环弧）使用金币解锁，每局选一个。
- 三皮肤、三玩家技能配色（均含默认项），不改变敌方预警语义或皮肤属性。结算含金币、贡献、纪录、下一解锁，主动放弃单独显示提前收班。
- 标准每完成阶段12金币、通关70、每图首通额外30；击杀补充奖励每10个1金币、每局上限6。失败/提前收班保留完成收益，不兑换剩余零件或计时挂机收益。
- 本地版本校验主备保存、保存失败回滚、最近256个run ID去重；商店检查点保存当前RNG/商品/已售/刷新与技能冷却。只恢复波间，不保存任意战斗帧，无云同步。
- 三曲各32小节四段、每曲三个同步Ogg层，含旋律/和声/配器变化；14短音效，独立音量与Web手势启声。项目原创许可待公开发布前决定。
