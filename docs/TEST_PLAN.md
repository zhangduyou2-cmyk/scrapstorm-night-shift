## 运行和隔离

从实际项目目录运行固定版本引擎，资源变化后先 import。统一入口为 `tools/run_tests.py`；可指定单套脚本和独立日志标签：

```powershell
& '.\.tools\godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path . --editor --import
python tools/run_tests.py --label v05-final
python tools/run_tests.py --label v05-focused tests/test_overtime_review.gd
```

统一入口当前枚举 23 个套件；本轮最终 1,246 项通过，汇总为 `artifacts/v05-release-final-regressions.json`。后续改动应生成对应新报告，不能复用本次结果。逐套使用 `--test-settings`；设置带 PID 隔离，Profile 夹具用自有路径并清理。检查退出码、ERROR/SCRIPT ERROR、失败断言、泄漏和超时，不能只看退出 0。测试脚本和 artifacts 不进入游戏分发。

## 必测边界

- 无尽每三房真实首领、每轮轮换地图；目标房最早结束时间、商店/路线/暂停不推进战斗时钟。Boss 死亡与同帧玩家死亡只结算一次，失败不能触发补给回血。
- 路线选择保存原增益、下一风险、RNG 与购买状态；返回商店、刷新、重建 main 和恢复都不重复加成。进入下一房才把风险记为已经遭遇，商店更新不额外生成危险。
- 八增益文案对应真实数值或行为。护盾在技能释放当帧挡一次伤害；免伤不制造损伤记录，治疗不清除既有损伤，也不能复活健康已为零的机体。
- 六进化必须产生实际轨迹、连线、聚拢、弹跳、标记或连锁伤害；遮挡、对象上限、来源去重和失去前提后取消分别覆盖。新激光/爆炸辅助破节点是 v0.5 的有意规则，不能继续套用旧版“全部自动工具不破节点”的断言。
- Profile 迁移保留金币/收藏/记录/检查点且不重复退款；正常退出、替换旧续玩、重复结束、写盘失败与坏档均不能重复发奖。历史最多 100 局、结算编号最多 256 个，终身累计独立保留。
- 首领无伤与整局无伤只采真实受伤数据和有效完成条件；旧检查点缺指标、结算满血、Quick 或空退出不能冒充无伤。成就金币与基础金币可解释同一次到账，未获奖励不能装备。

不采集商店停留时长，也不添加相关遥测或存档字段。测试执行耗时可用于定位回归，不能混为玩家商店数据。

## 普通输入、难度和性能

正常输入探针只能操作移动、鼠标/回收、技能及合法商店/路线 API，不加血、加钱、直接扣敌人血或跳过阶段；种子、最终装备、战斗时长、胜败和策略限制必须保留。新工具候选仍有随机性，没形成目标构筑的局不能算该构筑验证成功。

当前工具探针 `artifacts/v05-arsenal-probe-final.json` 与旧发现保障前基线分开，无尽探针见 `artifacts/v05-overtime-probe-final.json`。保留真实失败，包括无尽三图起点策略未完成其目标的样本；不推断玩家胜率、全构筑有效或三图必定通关。自动策略快速响应预警不等于真人反应。

高密度夹具可人为维持敌人/弹体/危险区并配置无敌，但必须公开设置。headless 测量只说明逻辑执行；实际渲染测量应记录设备、窗口、分辨率、持续帧数、平均值/P95/最大尖峰、是否含完整 HUD 和音频。v0.4 四工具世界夹具只作历史比较；本轮无尽四槽、新武器和完整界面需本轮数据，不宣称稳定 60 FPS 或最低配置保证。

## 平台交付

- Windows：构建按 `config/version` 输出到 `exports/windows-v0.5.0`；核对 EXE 版本资源、相邻 PCK/许可、ZIP 成员/字节/SHA256、解压一致性，并从导出和独立解压目录分别实际启动。
- Web：最终包通过本地 HTTP 和真实浏览器普通输入，检查默认英语/中文保存、主打无尽入口、工坊装备、首房/商店/路线、刷新继续、撤离或主动结束、历史/成就和重复结算。记录具体覆盖，未走完整首领或长局不得称已通关。
- 音频/窗口：检查手势启声、音量/静音、失焦暂停、输入释放、窗口缩放及减弱特效；功能性提示始终保留。
- 视觉：分别检查原生与 Web 的菜单、工坊、商店、路线、HUD、首领、历史/成就与结果，覆盖英中和 960 宽等关键尺寸。`?smoke=1` 仅只读观察，不提供作弊改局。
- 最终源码修复后重跑受影响验证并重导出，保存对应包哈希；较早包的普通输入结果必须注明版本差异，不能套用最终包哈希。
