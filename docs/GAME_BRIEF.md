# SCRAPSTORM: NIGHT SHIFT · 当前玩法

更新：2026-09-07，v0.5.1 首领 B 方案本地可玩版；无尽与档案基础沿用 v0.5。Windows 新版目录为 `exports/windows-v0.5.1`，由项目版本自动命名；Web 为 `exports/web`。下文描述已接入的玩法，首领新规则见 [B 方案](BOSS_COUNTER_B.md)；最终导出、整局验证与限制见[构建报告](BUILD_REPORT.md)。[原案](reference/ORIGINAL_CONCEPT.md)保持历史，不覆盖后续已确认的方向。

## 项目定位

免费、单人、2D 俯视角动作生存作品集。玩家驾驶改装清扫机器人，击碎失控机械、吸回零件、喷射解围，在商店改造装备，并决定继续深入还是带着战利品撤离。Codex 主导实现，创作者负责方向与试玩反馈。使用 Godot Standard、typed GDScript、Compatibility，面向 Windows x64 与桌面 Web；首启英语，游戏内可选并保存简体中文。

## 三个可玩模式

| 模式 | 当前入口与节奏 |
|---|---|
| OVERTIME 无尽加班 | 主菜单突出入口；选择起始区域，每房补给、每三房一个首领，首领后可撤离或继续 |
| NIGHT SHIFT 标准夜班 | 每局选择一张区域，五个普通阶段加最终首领，目标 15—20 分钟战斗 |
| QUICK SWEEP 极速清扫 | 三分钟短局，保留核心移动、回收、喷射和主动技能循环 |

标准模式的三张地图全部开放。无尽每三房构成一轮，下一轮轮换到另一张地图及对应音乐；三轮依次覆盖全部三个区域，随后继续循环。CONTRACTS 挑战合同仍是后续方向，当前没有不可玩的入口。旧 5×55 秒 Demo 只保留兼容测试用途。

普通敌人由基础角色发展为各图的行为、数值和绘制变体，不宣称九套完全独立 AI。首领保留两阶段招式与主动反制。常态本体承伤为回收场 55%、铸造厂 50%、反应堆 45%。成功破招提供 6 秒完整暴露，喷射补满当前容量、技能 +30；本体无接触伤害，原敌弹/危险区清除，存活支援小怪瘫痪两秒。暴露时喷射 1.85、主动技能 1.50、其他伤害 1.65 倍。喷射与主动技能仍是破节点的重要手段；v0.5 新增激光和爆炸武器也能命中节点，为构筑提供辅助反制。已提交冲撞不无预警追踪，预警与真实碰撞路径一致。实际难度继续由真人试玩判断。

首领入场一次把喷射储能补到至少 100 点并将技能充能置满，已有更高储能保留。诱撞压块直接破招；吸阀按有效进度补充最多 40 喷射/12 技能；反应堆每个节点返 45/12，近距持续吸附一秒也能拆除。电池无人机击毁后即时返 35/12，回流动画无需手动拾取；专用补给不产生零件或治疗。瞄准首领方向约 ±12.6° 内时，可锁定自动工具在自身射程和视线允许时优先选择首领。完整规则及验收边界见 [B 方案](BOSS_COUNTER_B.md)。

## 无尽：每次补给都要作选择

普通房轮换坚守、回收、歼灭与接力四种目标。坚守持续 65 战斗秒，其余普通房最多 80 秒；回收/歼灭/接力达标后可在至少 40 秒时提前完成。接力点需要靠近并持续吸附。首领房必须击败首领，不用计时器自动结束。

每个已完成房间进入商店。普通房工资 50 零件、最多修复 10 耐久；首领房工资 90、最多修复 25。完成指定目标额外获得 25 零件，地面剩余零件进入本局钱包。第三房起商店可能出现一次性修理候选；每店最多购买一次，不增加最大生命。

购物后查看三条路线，每条同时给出本局增益和下一房风险。选择一次即可锁定，可返回商店继续整备；选择、增益与下一房风险保存到检查点，重启不能重复领取。部署前仍可自由思考；已完成首领房可以直接安全撤离，不强制先选择下一条路线。

- 八类增益：工具伤害、回收范围、喷射容量、现场回收自愈、施放挡伤护盾、冲刺伤害泡沫、周期电弧和冷却加速。各最多五层，只持续本局；满层候选改为修复与零件补给。
- 六类风险：更多冲锋侧翼、横向危险带、残骸延迟爆炸、普通敌人增厚装甲、敌军移动超频和预判炮击。风险有预警，所选风险用于下一房；历史保留本局遇到过的风险。
- 房间深度提高敌人耐久，循环提升速度、伤害与后期危险压力。成长包含新目标、装备、行为进化和风险选择，不单靠延长血条。
- 失败仍结算已完成房间。撤离、提前收班与机体报废是不同结果；无尽不会颁发标准模式通关或技能精通徽章。

## 标准阶段、资源与商店

标准五阶段时长为 120/165/180/195/210 秒，共 870 战斗秒，分别强调回收聚怪、突进夹击、远程突破、场地回收与混合围攻，再挑战首领。标准波末工资 18 零件，免费修复至多 20 耐久。死亡优先于同帧胜利，奖励只结算一次。

商店和路线页冻结战斗、伤害与冷却，**不记录商店耗时**。现场每累计回收 25 零件修复 8 耐久；消费不倒扣累计回收，也不能在死亡后复活。

| 资源 | 获得与作用 |
|---|---|
| 局内零件 | 现场/波末回收、工资和事件；用于本局购买、刷新、修理与换装 |
| 喷射能量 | 现场回收与首领专用补给充能，基础容量 100；释放吸附时消耗并形成喷射 |
| 主动技能充能 | 独立 0—100，出勤即满；现场回收、限速的非技能首领伤害与专用补给回充；施放消耗满条 |
| 局外金币 | 已完成内容、封顶击杀、通关/撤离与一次性成就奖励；用于收藏与蓝图，不持续堆叠战斗属性 |

标准每完成阶段 12 金币、通关 70、首次区域通关额外 30，击杀奖励每十台一金币、每局最多六。达到击杀上限时，标准首通基础 166、重复通关基础 136；**成就奖励另外计入**。无尽基础为完成房间×8＋首领×20＋min(10, floor(击杀/20))；首领房撤离额外 min(40, 首领×10)。失败保留已完成奖励，零房零击杀退出不发金币。商店余额和停留时间不兑换金币。

工具共有八类，标准三个槽、无尽四个槽，均包含初始滚刷，最高三级。六种三级机体改装影响生命、机动、回收范围、容量、伤害和冷却。每店三候选、一次付费刷新、一次拆卸非滚刷工具；拆卸按已购等级在第一店的成本之和退 35%，不退后续店溢价，避免买卖套利。标准价格倍率 2.8，无尽 1.35；逐店附加与刷新价在第五店档位封顶，避免长期无限涨价。

## 主动技能、工坊与成就

默认拥有工业黄、薄荷绿、电磁排斥和电弧过载。金币可解锁极地/危险作业机体、冰川/紫外配色以及 160 金币的黑洞压缩器。工坊提供真实装备摘要、原创动态机体和技能演示；可将未拥有的商店物品设为目标，成功购买后清除目标。

| 主动技能 | 基础行为 | 第二、第四补给可选分支 |
|---|---|---|
| 电磁排斥 | 半径 185 的解围冲击、强击退与近弹清除 | 随身防护 / 延迟回声 |
| 黑洞压缩器 | 准星选择最多 260 距离的落点，牵引 1.5 秒后爆破 | 扩大聚怪 / 延迟追加爆破 |
| 电弧过载 | 五秒工具实际加速、机动增益、重置冲刺与环身电弧 | 工具/侧弧强化 / 机动/轨迹强化 |

每技能两条互斥分支，第二次补给选方向、第四次强化；第二次跳过，可在第四次首次选择。主动技能使用独立充能条，没有第二套长冷却。HUD 显示充能、就绪、施放中与剩余持续；失败有明确反馈，不扣资源。自身技能对首领的伤害不直接循环充能；击破电池/机关可领取该目标一次外部补给，商店不能站着充满。

战斗历史保留最近 100 局明细，另有终身击杀、回收、战斗时长与最高无尽房间/循环纪录。档案每页六局、可选择详情；成就展柜显示进度、奖章和实际奖励预览。

16 项成就提供短中长期目标：三图通关、全图收集、首领与整局无伤、无尽 3/6/12/24 房、首领/撤离、指定三种进化累计、回收与击杀里程碑。奖励为一次性金币、原创奖章、钴蓝/极光机体、余烬/棱镜配色和四个称号，可主动装备，不提供永久属性。完整条件、配色和奖励表见[战斗档案与成就](V05_BATTLE_ARCHIVE_AND_ACHIEVEMENTS.md)。

无伤按实际受伤累计判断，治疗后满血不能补回资格；Quick、短局放弃或旧检查点缺失指标不能代替无伤挑战。标准地区徽章和“三次标准胜利、每次至少三次技能施放”的精通徽章继续保留。

## 本地保存与使用边界

存档 v1/v2 兼容迁移到 v3，保留金币、收藏、选择、纪录、徽章与检查点。v1 曾购买过载者退款 180 一次，v2 不重复退款。购买、装备、金币/成就结算、历史与续玩清除一并落盘；失败全部回滚。最近 256 个 run ID 防止普通流程重复结算。

标准和无尽都在商店保存。检查点包含当前玩法/商店 RNG、货币/生命、装备、已售、刷新/拆卸、技能充能/分支、无尽路线/增益以及受伤/首领/进化记录；重读不能重选或重复领增益。替换已保存出勤会先按其真实状态结算为提前收班，再开始新模式。

战斗中没有逐帧自动保存，继续从最近商店恢复。Windows 与 Web 本地存档不互通，没有云账号、同步或历史外发；当前未实现历史导出按钮。

WASD 移动、鼠标瞄准、右键回收/释放喷射、空格冲刺、E 主动技能、Esc 暂停。支持改键、回收按住/切换、可跳过和重看的首局行动引导。暂停/失焦取消持续输入，恢复需要新的操作，避免误喷。

主菜单使用本轮生成的机库主视觉、独立真实装备摘要和英中文字排；战斗保持清楚的程序绘制机体/危险提示。减弱特效保留必要功能图形；短击停、冲击圈与世界震动不移动 HUD。三首原创配乐各有同步基础/节奏/首领层，跨图淡化，音乐与音效独立音量；测量通过不等于真人听感认可。

当前不做联机、移动触控、付费系统、大型剧情或云服务。无尽深层难度、长期构筑吸引力与音乐接受度仍需真实试玩；状态夹具和自动探针只说明对应路径能够运行。
