## 已实现的无尽循环

- [x] OVERTIME 为主入口，保留三图 NIGHT SHIFT 和三分钟 QUICK SWEEP；选起始区域、技能及外观后出勤。
- [x] 每三房一个区域首领，每轮结束后轮换地图及分层音乐。普通房包含坚守、回收、歼灭、吸附接力；坚守 65 战斗秒，其余普通房最多 80 秒，目标达标后最早 40 秒结束。首领房必须击败首领。
- [x] 每房商店无限停留且不计时。离店三选一，安装当局增益并公开下一房风险；原选择可保存，返回商店、刷新和续玩不会再次获得同一增益。
- [x] 首领商店可安全撤离或继续同一局。失败仍结算已完成内容；同帧玩家/首领均死亡时登记首领房并以失败结算，不回血、不进店、不发撤离奖励。
- [x] 三图敌群、远程/精英组合、场地危险与阶梯强度共同形成压力；速度、伤害与活动对象有界，不单靠解除数量上限。
