# v0.5.1 · 首领 B 方案

状态：B 方案已完成本地实施。v0.5.1 双端已导出，最终 25 套 Godot 回归 1,390 项通过，原导出与独立解压 Windows 程序均已实际启动并退出 0。首领隔离样本、原生 HUD 与 Web 普通输入各自的覆盖边界见[构建报告](BUILD_REPORT.md)，不沿用旧 v0.5.0 验收。

## 决策：稳定输出、破招补能、集中爆发

三图首领战采用同一节奏：常态仍能靠已装备工具稳定推进血条；玩家通过各图可读机制破招，获得喷射与技能补给；在明显的暴露窗口集中使用已积蓄的喷射、技能和自动工具。反制的价值由资源和可利用的输出机会共同表达，不能只把常态伤害压得很低后要求等待。

沿用右键回收/释放喷射、E 主动技能和现有自动工具。鼠标瞄准首领时，可锁定目标的自动工具优先攻击首领，减少爆发窗口被杂兵分散。不开新左键基础枪，不增加货币类型，不改商店自由停留和禁止计时的决定。范围覆盖标准夜班和无尽中的三图首领。

`boss_supply(energy_amount, skill_amount, fill_energy=false)` 即时注入现有喷射能量和独立技能充能，没有等待飞行后结算的拾取物，也不是第五种玩家资源。它不能走普通零件回收来制造钱包收入、累计回收、25 零件治疗、回收自愈、连击奖励或相应成就进度。普通可回收废料保留原规则。主动技能对首领本体的伤害仍不直接回充；技能击破电池或机关时，可以获得该目标的一次固定外部补给。电池击杀仍属于真实敌人击杀，专用补给本身不额外发币。
